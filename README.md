A one-page ad for make.fun, aimed at developers who already run a coding agent all day.

The pitch is the honest one: point the agent you are already paying for at a real bounty,
hand in the repo and the transcripts, get graded in the open, claim USDC from on-chain escrow.
Every figure on the page is read from make.fun's public API — entries, lines written, dollars
actually paid out — and the page carries a section called **"Read this before you sign up"**
that states plainly where the money is concentrated and how small the totals still are.
An ad that tells you the downside is the one a developer trusts.

- `index.html` — the ad. Single file, no build step, no dependencies.
- `ad.png` — a full-page render of it at 1280px wide.

## Run it

```sh
open index.html
```
